# gorsel.py Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gemini API'siz görsel adımı: sahne/karakter istekleri (referans listesi + prompt) üret, elle üretilen görselleri doğru ada ve 1080×1920 boyuta yerleştir, durumu göster.

**Architecture:** Tek modül `kod/gorsel.py`. Saf fonksiyonlar (tarif okuma, prompt, dosya adları, durum) ffmpeg/ffprobe çağıran iki küçük fonksiyondan ve `main(argv)`'den ayrı. Testler saf kısmı ve geçici klasörde ffmpeg'li yerleştirmeyi dener.

**Tech Stack:** Python 3.12 standart kütüphane, ffmpeg/ffprobe (PATH), `senaryo.senaryo_yukle`.

**Spec:** `docs/superpowers/specs/2026-11-26-gorsel-design.md`

## Global Constraints
- `pathlib.Path` ile yollar; dosyalar `encoding="utf-8"`; ffmpeg/ffprobe `shutil.which` ile; `subprocess` liste ile, `shell=True` yok.
- Tüm mesajlar Türkçe; `sys.stdout.reconfigure(encoding="utf-8")` `__main__`'de.
- Varyant harfleri `a, b, c`; sahne görseli `sahne{no}_{harf}.png`, tam 1080×1920. Karakter referansı `karakterler/<kimlik>.png`, kesilmez.
- Oran uyarısı: kaynak en/boy oranı 9/16'dan göreli olarak %10'dan fazla saparsa.
- Testler düz Python (`kod/test_senaryo.py` düzeni: `test_*` fonksiyonları + aynı koşucu). Gemini API hiçbir yerde yok.
- Commit yalnızca kullanıcı onayından sonra, en sonda tek commit.

## Review Focus
- İndirilenler'de hiç/az görsel var → "N görsel gerekiyordu, M bulundu" hatası, hiçbir dosya yazılmaz. (Task 2 testi)
- Kaynak dosya yok / görsel değil (ffprobe okuyamaz) → Türkçe hata, hedef dosya oluşmaz. (Task 2 testi)
- 3 harf dolu iken `--yeniden` olmadan yerleştirme → hata, mevcut dosyalara dokunulmaz. (Task 1 testi)
- `hikaye.md`'de bir karakterin bölümü yoksa → o kimlik sözlükte yok, prompt kurulurken açık hata. (Task 1 testi)
- Karakterli sahnede referans eksik → istekler dosyasında prompt yerine `--karakter` komutu. (Task 1 testi)

### Task 1: Saf kısım (tarif, prompt, adlar, istekler, durum)

**Files:**
- Create: `kod/gorsel.py`, `kod/test_gorsel.py`

**Interfaces (Produces):**
- `class GorselHatasi(Exception)`
- `Karakter = namedtuple("Karakter", "ad gorunus")`
- `karakter_tarifleri(hikaye_metni: str) -> dict[str, Karakter]` — `### <Ad>` başlıklı bölümlerden; kimlik `- **Referans:** \`karakterler/<kimlik>.png\`` satırından, görünüş `- **Görünüş:**` satırından (`**` temizlenmiş), ad başlıktaki parantezden önceki kısım.
- `referans_yolu(kok: Path, kimlik: str) -> Path`; `eksik_referanslar(kimlikler, kok) -> list[str]`
- `sahne_promptu(sahne: dict, karakterler: dict[str, Karakter]) -> str` — stil + "Ekteki {i}. görsel: {ad} — {gorunus}" + `gorsel`; bilinmeyen kimlikte `GorselHatasi`.
- `karakter_promptu(karakter: Karakter) -> str` — stil + beyaz düz arka plan, boydan, önden, tek figür.
- `varyant_yolu(klasor: Path, no: int, harf: str) -> Path`; `hedef_yollar(klasor, no, adet, yeniden) -> list[Path]` (boş harfler sırayla; yeniden=True ise a'dan; yetmezse `GorselHatasi`).
- `oran_uyarisi(gen: int, yuk: int) -> str | None`
- `istekler_metni(veri, karakterler, kok) -> str` (markdown); `durum_metni(veri, klasor, kok) -> str`

### Task 2: Yerleştirme (ffmpeg) ve komut satırı

**Interfaces:**
- Consumes: Task 1'in tümü, `senaryo.senaryo_yukle`, `senaryo.KARAKTERLER`.
- Produces: `boyut_oku(dosya: Path) -> tuple[int, int]` (ffprobe; okunamazsa `GorselHatasi`); `sahneye_yerlestir(kaynak: Path, hedef: Path) -> str | None` (scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920; oran uyarısını döndürür); `karaktere_yerlestir(kaynak, hedef) -> None` (PNG'ye çevir); `en_yeni_gorseller(klasor: Path, adet: int) -> list[Path]` (png/jpg/jpeg/webp, mtime'a göre yeni→eski, yetmezse `GorselHatasi`); `main(argv) -> int`.
