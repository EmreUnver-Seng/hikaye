# montaj.py Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bir bölümün görsel + ses + kelime zamanlamalarından 1080×1920 videoyu (zoom, vurgulu altyazı, seçenek kartı) ffmpeg ile üreten `kod/montaj.py`.

**Architecture:** Saf Python katmanı (girdi toplama, zaman çizelgesi, altyazı gruplama, ASS metni, ffmpeg komut listeleri) ffmpeg'siz test edilir. ffmpeg katmanı: ffprobe ile süre, sahne başına klip, kart klibi, tek geçişte birleştirme. Geçici iş klasörü bölüm klasörünün içinde, ffmpeg `cwd` orada, ASS/font göreli yollarla.

**Tech Stack:** Python 3.12 standart kütüphane, ffmpeg/ffprobe (libass, zoompan, libx264).

**Spec:** `docs/superpowers/specs/2026-11-26-montaj-design.md`

## Global Constraints
- 1080×1920, 30 fps; H.264 `yuv420p` CRF 20; AAC 192k; `+faststart`.
- Cümle arası 0,15 sn; sahne sonu 0,35 sn; kart 4 sn; zoom 1,00↔1,08 (tek sahne yakınlaşır, çift uzaklaşır), kart zoom 1,04 + %60 karartma.
- Altyazı: Montserrat ExtraBold 86 px, beyaz, vurgu `#E8B82D` (ASS `&H002DB8E8`), kontur 7, gölge 3, alt-orta, MarginV 420, MarginL/R 80. Grup ≤4 kelime ve ≤22 karakter.
- Font ayarı modül başında tek yerde: `FONT_DOSYASI = "Montserrat-ExtraBold.ttf"`, `FONT_ADI = "Montserrat ExtraBold"`.
- `pathlib`, `encoding="utf-8"`, `shutil.which`, komutlar liste, `shell=True` yok; `sys.stdout.reconfigure(encoding="utf-8")`.
- Testler düz Python (`python kod/test_montaj.py`), pytest yok. Commit yalnızca kullanıcı onayından sonra, en sonda tek commit.

## Review Focus

### Task 1: Girdi toplama, bayraklar, zaman çizelgesi

**Files:** Create `kod/montaj.py`, `kod/test_montaj.py`

**Interfaces (Produces):**
- `class MontajHatasi(Exception)`: `.hatalar: list[str]` (tek mesaj da listeye konur).
- `sahne_secimi(metin: str | None, veri: dict) -> list[int]`: `None` → tüm sahneler; `"3"`, `"1-3"`; senaryoda olmayan / ters aralık → `MontajHatasi`.
- `varyant_secimi(metin: str | None, veri: dict) -> dict[int, str]`: `"3=b,5=c"`; harf `a/b/c`, sahne var olmalı.
- `CumleGirdisi(anahtar: str, mp3: Path, kelimeler: list[dict])`, `SahneGirdisi(no: int, gorsel: Path, cumleler: list[CumleGirdisi])` (namedtuple).
- `girdileri_topla(veri, klasor: Path, sahneler: list[int], varyantlar: dict[int,str]) -> list[SahneGirdisi]`: tüm eksikleri toplayıp tek `MontajHatasi`; mesajlar `gorsel.py ... --yerlestir N` / `ses.py ... --sahne N` komutunu içerir. Anahtar `ses.dosya_adi` ile (import), kayıtlar `ses.kayitlari_yukle`.
- `Cizelge(sahneler: list[(no, gorsel, baslangic, kare)], cumleler: list[(anahtar, mp3, baslangic, slot_bitis, kelimeler)], kart_baslangic: float, kart_kare: int, toplam: float)`.
- `zaman_cizelgesi(girdiler: list[SahneGirdisi], sureler: dict[str, float]) -> Cizelge`. Sahne süresi = Σmp3 + 0,15×(n−1) + 0,35; `kare = round(süre*30)`; sahne başlangıcı = önceki kareler toplamı/30; cümle başlangıcı = sahne başlangıcı + sahne içi ofset; `slot_bitis` = sonraki cümle başlangıcı (son cümlede sahne bitişi). Kart kare = 120.

### Task 2: Altyazı ve kart (ASS)

**Interfaces (Produces):**
- `gruplara_bol(kelimeler: list[dict]) -> list[list[dict]]`: ≤4 kelime, ≤22 karakter (boşluklar dahil; tek kelime 22'yi aşsa da kendi grubu), `.?!…` ile biten kelimeden sonra kapat, `,` ile biten kelimede grup ≥2 ise kapat.
- `ass_zaman(sn: float) -> str` → `"0:00:01.23"` (santisaniye, yuvarlama).
- `ass_kacir(metin: str) -> str`: `\` → `/`, `{`→`(`, `}`→`)`.
- `altyazi_olaylari(cizelge: Cizelge) -> list[str]`: her kelime için bir `Dialogue` satırı; grup metni, aktif kelime `{\c&H002DB8E8&}…{\c&H00FFFFFF&}`. Olay süresi: kelime başlangıcı → sonraki kelime başlangıcı; grubun son kelimesi → sonraki grubun ilk kelimesi, cümlenin son kelimesi → `min(bitis+0.3, slot_bitis)`. Zamanlar mutlak (cümle başlangıcı + kelime zamanı).
- `kart_olaylari(ikilem: dict, baslangic: float, sure: float) -> list[str]`: stiller `Soru` (72), `Secenek` (64, BorderStyle 3), `Not` (48); A/B `\fad(250,0)` ve 0,25 sn gecikme; `secenekler` yoksa yalnızca soru + "Yorumlara yaz", varsa alt satır "Yorumlara A ya da B yaz". Konumlar `\pos(540,y)`: soru ~%35, A %52, B %62, not %75.
- `ass_metni(cizelge: Cizelge, ikilem: dict) -> str`: başlık (`PlayResX: 1080`, `PlayResY: 1920`, `WrapStyle: 0`), stiller (`Alt` Global Constraints değerleriyle, font `FONT_ADI`), olaylar.

### Task 3: ffmpeg komutları, render ve CLI

**Interfaces (Produces):**
- `ses_suresi(mp3: Path) -> float` (ffprobe `format=duration`).
- `klip_komutu(gorsel: str, kare: int, zoom_bas: float, zoom_bit: float, cikti: str, karart: bool=False) -> list[str]`: `-loop 1 -framerate 30 -i gorsel`, `scale=2160:3840,zoompan=z='bas+(bit-bas)*on/(kare-1)':x=…:y=…:d=1:s=1080x1920:fps=30`, karart → `,eq=brightness=…` yerine `colorchannelmixer` ile ×0.4; `-frames:v kare`, libx264 ayarları.
- `ses_filtresi(cizelge: Cizelge, ilk_girdi: int) -> str`: her mp3 `[i:a]aresample=44100,aformat=channel_layouts=mono,apad=whole_dur=<slot>[aK]`, kart `anullsrc=r=44100:cl=mono,atrim=duration=<kart>[aN]`, `concat=n=…:v=0:a=1[ses]`. Slot = slot_bitis − baslangic; ilk cümle 0'da değilse (olamaz, sahne 0'da başlar) yok.
- `birlestirme_komutu(liste: str, mp3ler: list[str], ass: str, fontlar: str, filtre_ses: str, cikti: str) -> list[str]`: `-f concat -safe 0 -i liste`, mp3 girdileri, `[0:v]ass=<ass>:fontsdir=<fontlar>[v]`, `-map [v] -map [ses]`, kodlama ayarları, `-shortest` yok.
- `montajla(veri, klasor: Path, sahneler, varyantlar, kuru=False, sure_olc=ses_suresi) -> Path | None`: topla → süre ölç → çizelge → (`kuru`: plan yazdır, None) → `TemporaryDirectory(dir=klasor)`: kliplerin hepsi, `klipler.txt`, `altyazi.ass`, birleştirme (`cwd=is_klasoru`, tüm yollar `os.path.relpath(..., is_klasoru)` + `as_posix`) → `cikti.tmp.mp4` → `replace`. Çıktı adı: `sahneler` tüm sahneler ise `video.mp4`, değilse `onizleme.mp4`. Tam montajda 45–90 sn dışı uyarı. ffmpeg hatası → `MontajHatasi` (stderr son satırları).
- `main(argv) -> int`: `senaryo`, `--sahne`, `--varyant`, `--kuru`; hatalar Türkçe, çıkış 1.
