# ses.py Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Senaryodaki her cümleyi konuşanın sabit ElevenLabs sesiyle seslendiren, kelime zamanlamalarını kaydeden, kotayı koruyan `kod/ses.py`.

**Architecture:** Saf fonksiyonlar (eşleme doğrulama, iş listesi, kelime çıkarma) + istemciyi parametre alan tek bir `seslendir()` akışı + `main()`. Testler sahte istemciyle ağsız çalışır.

**Tech Stack:** Python 3.12, `elevenlabs` SDK 2.80.0 (`text_to_speech.convert_with_timestamps`, cevap alanları `audio_base_64`, `alignment`, `normalized_alignment`; `user.subscription.get()` → `character_count`, `character_limit`), `python-dotenv`.

**Spec:** `docs/superpowers/specs/2026-11-26-ses-design.md`

## Global Constraints
- `pathlib.Path`; tüm dosyalar `encoding="utf-8"`; `sys.stdout.reconfigure(encoding="utf-8")` yalnızca `main`'de.
- Tüm kullanıcı mesajları Türkçe; anahtar asla ekrana yazılmaz.
- pytest yok: `kod/test_ses.py` düz Python, `test_*` fonksiyonlarını sırayla çalıştırır (`test_gorsel.py` düzeni).
- Ses biçimi `mp3_44100_128`; `language_code="tr"`, model `eleven_multilingual_v2` ise gönderilmez.
- Commit yalnızca kullanıcı onayıyla, en sonda tek commit (görev başına commit yok).

## Review Focus
1. Senaryoda cümle metni düzeltilince yalnızca o cümle yeniden üretilmeli → Task 3 `test_metin_degisince_yeniden`.
2. API 3. cümlede hata verirse ilk 2 cümlenin kaydı ve dosyası kalmalı, tekrar çalıştırınca atlanmalı → Task 4 `test_yarida_hata_kayit_korunur`.
3. `.env`'de anahtar yokken `--kuru` yine sayım yapmalı, kota "bilinmiyor" → Task 4 `test_kuru_anahtarsiz`.
4. `zamanlama.json` bozuk/boşsa çökmemeli: Türkçe hata ("sil veya düzelt") → Task 3 `test_bozuk_zamanlama`.
5. Metin başında/sonunda veya arada çift boşluk → boş kelime üretmemeli → Task 2 `test_coklu_bosluk`.

### Task 3: İş listesi (atlama, kapsam, eksik ses, sayım)

**Interfaces — Produces:**
- `dosya_adi(sahne: int, cumle: int) -> str` → `"s03_c2"` (uzantısız anahtar; dosya `+ ".mp3"`).
- `Is = namedtuple("Is", "anahtar sahne cumle konusan metin ses_id uret")` (`ses_id` eşlemede yoksa `None`).
- `kayitlari_yukle(klasor: Path) -> dict` → `zamanlama.json`'daki `cumleler` (dosya yoksa `{}`; bozuksa `SesHatasi`).
- `isleri_hazirla(veri: dict, harita: dict, kayitlar: dict, klasor: Path, sahne: int | None = None, cumle: tuple[int, int] | None = None) -> list[Is]` — `uret=False` yalnızca mp3 var **ve** kayıttaki `metin`, `ses_id`, `model` aynıysa; `cumle` verilirse o tek iş `uret=True`. Olmayan sahne/cümle → `SesHatasi`.
- `eksik_sesler(isler: list[Is]) -> list[str]` — sesi olmayan konuşanlar, sıralı, tekrarsız.
- `karakter_sayisi(isler) -> int` — yalnızca `uret=True` olanların `len(metin)` toplamı.

- [ ] **Step 1: Testler** (geçici klasörde, `test_gorsel.py` gibi örnek veriyle): `test_dosya_adi` (`(3,2)→"s03_c2"`, `(12,1)→"s12_c1"`); `test_hepsi_yeni`; `test_var_olan_atlanir`; `test_metin_degisince_yeniden`; `test_ses_veya_model_degisince_yeniden`; `test_mp3_silinmisse_yeniden`; `test_sahne_kapsami`; `test_cumle_zorla` (var olan cümle `uret=True`, başka iş yok); `test_olmayan_numara` (sahne 99, cümle `(1, 9)` → `SesHatasi`); `test_eksik_sesler` (`riza` konuşursa `["riza"]`); `test_karakter_sayisi`; `test_bozuk_zamanlama`.

### Task 4: Seslendirme akışı + CLI

**Interfaces — Consumes:** Task 1–3. **Produces:**
- `seslendir(veri: dict, klasor: Path, harita: dict, istemci, sahne=None, cumle=None, kuru=False, sor=input, yaz=print) -> int` (çıkış kodu). `istemci` `None` olabilir (anahtar yok): yalnızca `kuru=True` ile kabul, aksi hâlde `SesHatasi`.
- `kalan_kota(istemci) -> tuple[int, int] | None` → `(kalan, limit)`.
- `main(argv) -> int`; argümanlar: `senaryo`, `--sahne N`, `--cumle S.C` (biçim hatası Türkçe), `--kuru`; `--sahne`/`--cumle` birlikte → hata. Çıktı klasörü: senaryonun yanındaki `sesler/`.

Akış ve mesajlar spec "Akış" 1–9 ile birebir. `zamanlama.json` her cümleden sonra `.tmp`'ye yazılıp `Path.replace` ile değiştirilir; kök `{"bolum": N, "cumleler": {...}}`. API hataları (`elevenlabs.core.api_error.ApiError`, `status_code` + `body`): 401 → "anahtar geçersiz", gövdede `quota_exceeded` → "kota bitti", 404/`voice_not_found` → "sesler.json'daki ID'yi kontrol et", diğer → durum kodu + kısa gövde.
